TableTurn

Sep 2026 · AI-native, spec-first build
Idea → Spec via Agent AI Agent-Built AI-Native Software Delivery API Contract-Driven

TableTurn is a restaurant waitlist manager built end-to-end using an AI-native software development workflow — with agents driving the journey from idea to working application.

The project started with nothing more than a vague idea: “something to manage restaurant waitlists.” A planning agent turned that idea into a concrete product specification through an iterative conversation — clarifying who the users are, defining what the V1 should and should not do, and designing the underlying data model.

That conversation produced two important artifacts: a written product specification and an AGENTS.md defining the project’s engineering conventions and development workflow.

A coding agent then implemented the application against those specifications. The React frontend was developed first against a mocked API, allowing the user experience to evolve independently of the backend. In parallel, the API design was captured as an OpenAPI specification, defining how the frontend and backend would communicate.

Next, a test-first FastAPI + SQLite backend was built against the same OpenAPI specification. This specification served as the shared contract between the frontend and backend, allowing both sides to be developed independently while maintaining a consistent interface.

Once both the frontend and backend were working independently, they were integrated and the persistence layer was switched to a live database. Because the API design remained unchanged, the database change was isolated to a single file rather than requiring changes throughout the application.

The result demonstrates a different way of building software:

Idea → Product Specification → API Design → Implementation → Integration

Instead of AI simply generating code, the project uses AI agents as participants in a structured engineering workflow — with specifications, API definitions, tests, and engineering conventions providing the guardrails.

The idea shaped the product specification. The specification shaped the API design. The API design guided the implementation. And the agents built to it.
